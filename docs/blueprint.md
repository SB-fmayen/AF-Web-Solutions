# **App Name**: WebCraft Studio

## Core Features:

- Home Page with Clear Value Proposition: A landing page with a concise statement of services and a prominent call-to-action button: "Cotiza tu página".
- Services Showcase: Detailed presentation of website creation packages, highlighting features and pricing.
- Portfolio Display: A section featuring 2-3 demo projects showcasing the range and quality of website designs.
- About Me Section: An informative page about the web creator, focusing on their background and unique selling points.
- Contact Information: Integrated WhatsApp link and a contact form for easy inquiries and communication.

## Style Guidelines:

- Primary color: Deep blue (#2E3192) to convey trust and professionalism.
- Background color: Light gray (#F0F0F0) for a clean and modern look.
- Accent color: Soft purple (#6658C1) for call-to-action buttons and highlights, offering a touch of creativity.
- Body font: 'PT Sans', a humanist sans-serif font providing a modern and readable experience for all text.
- Headline font: 'Space Grotesk', a geometric sans-serif font with a computerized, techy look, ideal for headlines.
- Clean, professional icons to represent services and enhance visual communication.
- Structured and intuitive layout to guide users through the site effectively.
- Preload animation and subtle transitions to create a smooth, professional user experience.
