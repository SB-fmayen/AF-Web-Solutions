# Carpeta para logos

Aquí puedes subir tu logo en los siguientes formatos:
- PNG
- SVG (recomendado)
- JPG/JPEG
- WebP

Ejemplo de nombres de archivos:
- `logo.svg`
- `logo.png`
- `favicon.ico`

Los archivos en esta carpeta serán accesibles en:
- `http://localhost:9002/logos/logo.svg`
- En producción: `https://tudominio.com/logos/logo.svg`
